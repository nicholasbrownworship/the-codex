Dungeons & Dragons

The Campaign: Issylra Reborn

🗺️

The Setting

A homebrewed version of Issylra — the least-explored continent in Critical Role's Exandria. The DM has done extraordinary heavy lifting to fully flesh it out, with the whole table contributing to the lore.

⏳

The Timeline

Set slightly before the Vox Machina era. The events of Campaign 1 haven't happened yet — which gives the group enormous narrative freedom while keeping the lore as a backbone.

🎵

The Soundtrack (Planned)

Orchestral compositions via Omnisphere and Ableton — original ambience, tension cues, and character themes for the campaign. The project is waiting for a free weekend to begin.
